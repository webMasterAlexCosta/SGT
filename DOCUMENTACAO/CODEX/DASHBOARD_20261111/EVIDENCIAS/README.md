# Acervo histórico anterior ao mockup de gestão

Os arquivos deste diretório registram a primeira implementação de 11/11/2026, anterior à proposta de gestão aprovada, à tempestividade capturada, à solicitação explícita de revisão e à regra de edição de 72 horas. Permanecem preservados como histórico. Suas imagens de fixture, equivalências de viewport e recibos não aprovam a implementação atual.

O checkpoint vigente está em [VERIFICACAO.json](../VERIFICACAO.json), com [fontes](../SHA256-FONTES.json), [artefatos](../SHA256-ARTEFATOS.json), [imagens reais](../IMAGENS/) e pareceres independentes ao lado. As limitações de zoom, plataforma e laboratório devem ser lidas no parecer final correspondente.

`CHECKS.log` tem somente a linha vazia excedente do fim removida para a higiene do diff; `CHECKS-original.log.gz` preserva os bytes originais desse recibo histórico. Nenhum deles é o log de validação R4.
